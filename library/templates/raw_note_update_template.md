# Raw Note Template — Entry Update

Use this lightweight template to record a change to an entry that is **already in the
inventory** — a status change, a new result, a new owner, expanded scope, a new risk.
The agent will match it to the existing record and update it; it will not create a
duplicate. Only write what changed — skip anything that's still the same.

**Filename convention:** `library/raw/YYYY-MM-DD_update_entry-slug.md`
Example: `library/raw/2026-07-01_update_pr-review.md`
