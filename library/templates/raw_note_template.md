# Raw Note Template — New Entry

Use this template when you want to document an entry directly rather than sharing a
transcript or meeting recording. Fill in what you know and leave the rest blank — the
agent will flag missing fields rather than invent them.

**Filename convention:** `library/raw/YYYY-MM-DD_short-entry-slug.md`
Example: `library/raw/2026-06-10_sprint-planning-assistant.md`
